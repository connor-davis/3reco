# Data Exports

Admins, staff and businesses can download CSV files of their records. The server builds each file and streams it, so large exports do not fill the browser's memory.

## What each role can export

| Route | Who | File |
|---|---|---|
| `GET /api/admin/exports/users` | Admin | `users.csv` |
| `GET /api/admin/exports/transactions` | Admin, Staff | `transactions.csv` |
| `GET /api/exports/collections` | Admin, Staff, Business (own purchases only) | `collections.csv` |
| `GET /api/exports/purchases` | Business | `purchases.csv` |
| `GET /api/exports/sales` | Business | `sales.csv` |

Any other role gets `403 forbidden`.

## Query

| Parameter | Meaning |
|---|---|
| `from`, `to` | The period, as RFC 3339 timestamps (for example `2026-11-01T00:00:00Z`). `to` must not be before `from` |
| `itemised` | `true` gives one row per material line; `false` gives one row per trade |

```typescript
const url = `/api/exports/purchases?from=${from}&to=${to}&itemised=true`
window.location.assign(url) // the browser downloads it with your cookie
```

## Good to know

- A cell that starts with `=`, `+`, `-` or `@` gets a leading `'` so a spreadsheet does not run it as a formula.
- Staff see bank account numbers masked. Admin and business see them in full, and an admin's full read is written to the audit log.
- An error before the file starts is JSON. A failure in the middle cuts the download.
